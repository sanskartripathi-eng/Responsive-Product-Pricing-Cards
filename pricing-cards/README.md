# Responsive Pricing Cards

A modern SaaS pricing card component with a Monthly/Yearly billing toggle, ribbon badges and hover effects. Plain HTML, CSS and JavaScript, no build step.

## Features
- Accessible billing switch (`role="switch"`) with animated price changes
- "Popular" and "Best Value" card ribbons
- CSS transitions and transform hover effects
- Responsive grid, light and dark mode, reduced-motion support

## Run it
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages) to host it.

## Customize
Edit the `plans` array and `YEARLY_DISCOUNT` at the top of the script in `index.html`.
